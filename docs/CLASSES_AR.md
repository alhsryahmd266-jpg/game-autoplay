# أسماء الكلاسات المفهومة للبوت

التطبيق بيفهم الكلاس من اسمه (إنجليزي). ولو اسمك مختلف استخدم "ربط الكلاسات بالأدوار" جوه التطبيق.

| الدور | أسماء بتتفهم |
|---|---|
| عدو | enemy, bot, opponent, hostile, target, soldier, person |
| رأس عدو | head, headshot |
| صديق | ally, friend, teammate |
| غنيمة / سلاح | loot, item, weapon, ammo, medkit, crate, pickup |
| عصا الحركة | joystick, stick, move |
| النار | fire, shoot |
| قفز / انحناء / انبطاح | jump / crouch / prone |
| تعبئة / علاج / تبديل | reload / heal / swap |
| التقاط | interact, pick, take, use |
| شريط الصحة | health, hp |
| صحة منخفضة | low_health |
| الخريطة | minimap, radar |
| مركز الزون / حافة الزون | zone_center / zone_edge, storm |
| زر قائمة (بعد الموت) | continue, retry, ok, play, respawn |

كلما صنّفت كلاسات أكتر، كلما لعب البوت أحسن. أهمها: enemy و joystick و fire.
